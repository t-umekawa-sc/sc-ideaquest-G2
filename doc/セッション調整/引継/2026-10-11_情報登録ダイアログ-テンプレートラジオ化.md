# 引き継ぎ: 情報を登録ダイアログの構成調整（配置タブ最上部化＋テンプレート=ラジオ2択）

- 日付: 2026-10-11
- 引き渡す側: 調査/設計セッション（情報登録ダイアログの UI 検討・モック作成）
- 対象: 情報インプット登録ダイアログ（SC-51 / `impl/frontend/src/features/info-input/components/InfoFormPanel.tsx`）
- 関連設計ドラフト: なし（検討モックで代替 → [doc/画面設計/mocks/_情報登録ダイアログ調整_検討.html](../../画面設計/mocks/_情報登録ダイアログ調整_検討.html)）

## 背景・目的

ユーザーが実機で「情報を登録」ダイアログを確認した際の指摘（2026-10-11）を受け、構成を調整する。実機スクショ URL = `localhost:3000/info-items/new?tab=…`。指摘は次の2点。

1. **配置（タブ）が上から2番目になっている**（現状はテンプレート→配置タブの順）。**配置（タブ）を最上部へ**。
2. **テンプレートは「選ぶと “以降の各項目” に下書き（タイトル/本文/属性既定）を流し込む」操作**であり、タイトル・本文…等の “内容メンテ項目” とは役割が異なる。**同じ入力欄の並びに混ぜず、見た目で区別**したい。

検討モックで select案 / タブ案 / ラジオ2択案 の3版を提示し、**ユーザー決定＝ラジオ2択案**（下記§確定仕様）。

## 調査結果（事実・すべて実コードで確認済み）

- 対象コンポーネント＝`impl/frontend/src/features/info-input/components/InfoFormPanel.tsx`（モーダル/フルページ両用の body/footer）。正＝`doc/画面設計/mocks/SC-50_情報インプット.html`（DoD＝モック一致）。
- **現状の描画順**（InfoFormPanel.tsx）＝ ①テンプレート（L233-240・`<Field class="dialog-section is-quiet">` 内の `<Combobox>`）→ ②続報 disclosure（親ありの時）→ ③配置（タブ）`.place-zone`（L258-267）→ ④タイトル… の順。**テンプレートが先頭**になっている（指摘1の原因）。
- テンプレート適用ロジック＝`applyTemplate(id)`（L102-123）。select の onChange で発火。選ぶと `title`/`body` と（curator のみ）属性既定をプリフィル。`""` で「使わない」。入力済みなら上書き確認ダイアログ（L105-108）。
- `.place-zone` CSS＝`impl/frontend/src/features/info-input/info-input.css` L309-321（薄グレー地＋**左 3px 青アクセント帯**＋角丸＋`margin-bottom`）。
- **`.place-zone` は2箇所で共用**＝`InfoFormPanel.tsx`（登録・L259）と `InfoDetailView.tsx`（詳細・L339）。**詳細側は最上部ではない／ヘッダー密着でもない**。→ ヘッダー密着化は登録側に限定する必要あり（§注意）。
- テンプレートは新規登録時のみ表示（続報・編集は非表示・L233 `!parentId && templates.length`）。配置（タブ）も新規のみ（続報は親タブ継承・L258）。

## 確定仕様（ユーザー決定・2026-10-11）

モック [_情報登録ダイアログ調整_検討.html](../../画面設計/mocks/_情報登録ダイアログ調整_検討.html) の内容で確定。要点：

1. **並び＝配置（タブ）を最上部へ**。現状の「テンプレート→配置タブ」を入れ替え、`配置（タブ）→ テンプレート → 区切り → タイトル…` の順。
2. **配置（タブ）ゾーン＝ヘッダー直下にマージン無しで密着（全幅バンド）**。
   - body の上・左右パディングを負マージンで打ち消して全幅化し、モーダルヘッダーの下罫にくっつける。
   - 上角の角丸なし（`border-radius: 0`）、下罫のみ（`border-bottom`）で本文と区切る。
   - **左アクセント帯は外す**（`border-left` の 3px 青帯を削除）。地色は従来どおり `--color-surface-alt`。
3. **テンプレート＝“下書きアシスト”ブロック（内容メンテ項目と別装い）**。
   - `--color-primary-soft` の塗りカード＋`✨` アイコンバッジ＋見出し「テンプレートから下書き（任意）」。
   - ブロック下端に下向きキュー「**▼ 選ぶと下の各項目に下書きが入ります**」。
   - テンプレートブロックと内容項目の間に区切り「**ここから入力・編集**」（破線＋中央ラベル）。
4. **テンプレート選択UI＝ラジオ2択＋選択時コンボ**（★本件の採用案）。
   - 上ラジオ＝「**テンプレートを使わない（白紙から入力）**」＝**既定選択**。コンボ非表示。
   - 下ラジオ＝「**テンプレートを選択する**」。これを選ぶと**直下にコンボ（テンプレ一覧）が出現**（字下げ）。コンボで実テンプレートを選ぶと `applyTemplate(id)` 発火。
   - 白紙ラジオに戻したら `selectedTpl=""` にリセット（適用解除の扱いは既存 applyTemplate の `""` 分岐を流用）。

モック該当箇所＝ファイル末尾の「別サンプル：ラジオ2択（白紙から／テンプレートを選択する）」セクション（2状態＝白紙選択/選択する＋コンボ表示を上下に並べて掲載）。CSS クラス参考＝`.tpl-zone` / `.tpl-radios` / `.tpl-radio` / `.tpl-combo-reveal`。

## 受け側への申し送り

- **前提/注意（最重要）**: `.place-zone` は**登録（InfoFormPanel）と詳細（InfoDetailView）で共用**。ヘッダー密着バンド化（負マージン・角丸0・下罫）を素の `.place-zone` に当てると**詳細ビューの表示が崩れる**。登録ダイアログの最上部に限定した**修飾子クラス**で適用すること。
- 注意: 負マージンでの全幅化は**モーダル body の padding 値（`--space-5`）に依存**。モーダルとフルページで body padding が異なる場合は要調整（InfoFormPanel は両用）。
- 未確定点: 現状テンプレートが0件だと `!parentId && templates.length` でブロック自体が非表示。ラジオ化後も**テンプレ0件なら従来どおりブロックごと非表示**でよい（白紙ラジオだけ出す必要はない）＝この前提で起票。異論あればユーザー確認。
- 挙動: テンプレ適用時の**上書き確認ダイアログ**（既存 L105-108）はラジオ案でも維持（コンボで実テンプレを選んだ時に発火）。
- アニメ: コンボの出現は reduce-motion 配慮（§4.9）。モックは静的なので実装側で判断（軽い高さ/フェードに留める・無しでも可）。
- 正本反映の想定先: `doc/画面設計/mocks/SC-50_情報インプット.html`（DoD＝モック一致の正）／必要に応じ `doc/画面設計/screens/SC-50_情報インプット.md`。反映は実装セッションが実施。
