## 1. 文書間参照の表記

文書間の参照が「どの文書の §か」曖昧だと**誤参照を誘発する**（節番号だけの参照は、別文書の同番号を指す事故が起きやすい）。次に統一する。

1. **文書間参照は対象文書名を接頭辞に付ける**（裸の `§x` は禁止）。
   - 例: `UI標準§6.9`／`権限・スコープ§3`／`画面遷移図§9-48`／`セキュリティ要件対応表§24`。
2. **同一文書内の参照は裸の `§4-2` でよい**（本文書内＝接頭辞不要）。
3. **紛らわしい同名系の文書は必ずタグで区別する**。名前が似ていて取り違えやすいもの（確定版/暫定版・新旧・要件版/設計版 など）は、引用時に版を明示する。
   - 例: `〇〇定義〔要件版・旧〕` と `〇〇確定〔確定版〕` を必ず書き分ける。
   - → **どのファイルがどの版か**の対応表は、各プロジェクトのインデックス文書に置く。
4. **節番号の区切りは引用先の見出しに忠実に**（`§9-48` のハイフン形と `§6.9` のドット形を勝手に統一しない＝忠実引用）。**曖昧さ解消の主役は接頭辞（文書名）**であって区切り記号ではない。
5. **可能なら markdown の相対リンク**でクリック到達性を確保（`[…](相対パス)`）。

## 適用チェック（レビュー時）
- 裸の `§x`（文書名接頭辞なし）が残っていないか。
- 紛らわしい同名系の文書に版タグが付いているか。
- 相対リンクが切れていないか。
