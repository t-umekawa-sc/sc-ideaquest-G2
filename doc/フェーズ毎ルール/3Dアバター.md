# 3Dアバターの進め方（SC-31・VRM 導入）

> このフェーズ（ゲーム感向上）における **3Dアバターの完成手順と役割分担**の正本。関連＝画面設計 [`../画面設計/screens/SC-31_アバター着せ替え.md`](../画面設計/screens/SC-31_アバター着せ替え.md) §9（3Dビューア/VRM の設計決定）／要件定義 §7（Three.js / R3F / three-vrm）。進め方全体＝[`ゲーム感フェーズ.md`](ゲーム感フェーズ.md)。

## 1. 現状（重要：完成版ではない＝プレースホルダ）
- `impl/frontend/src/features/avatar/components/AvatarViewer3D.tsx` は **R3F プリミティブの見立て**（球＋カプセルの簡易フィギュア・男女はベース色だけ）。**実 VRM は未導入**。
- 装備は **2D の絵文字重ね**（`.viewer__slot`・§9.2 seam）。3D の実パーツ反映も未実装。
- `items.part_ref`（装備の VRM 参照）は**未整備**（現状 item DTO にも無い・§9 で「アセット制作時に付与」と決定）。
- 精度が低いのは**想定どおりの暫定状態**。設計上「アセットを後から差し込む seam」で先行している。

## 2. ゴールと“契約”（設計で確定済み・SC-31 §9）
- **ベースアバター＝男女2体の VRM**（`male`/`female`）。**同一 humanoid リグ（VRM humanoid 規格）**で作る＝装備を性別ごとに二重制作しない（DRY）。
- **装備パーツ**＝各ショップアイテムに対応する3Dモデルを、スロット（head/face/body/hand）へアタッチ。`items.part_ref` にアセット参照を持たせる。**背景は 2D レイヤ**（3D不要）。
- 技術スタック＝**Three.js / React Three Fiber / @pixiv/three-vrm**（要件定義 §7・three-vrm は未導入＝結線時に追加）。
- WebGL 非対応/reduce-motion は既存のフォールバック（2D＋自動回転抑止）を維持（§9.3）。

## 4. あなたの作業＝VRM アセットの用意（方法・やり方）
### 4-1. 最短：VRoid Studio で自作（無料・推奨）
1. **VRoid Studio を入手**（pixiv 製・無料・Windows/Mac）＝ https://vroid.com/studio からダウンロード・インストール。
2. **モデルを作る**：新規作成→プリセットから人型を選び、髪型/顔/体型/衣装を調整。**男性寄り・女性寄りの2体**を作る。VRM は既定で humanoid リグなので、**2体とも標準の humanoid のまま**にする（ボーン構成を揃える＝装備使い回しの前提）。
3. **VRM で書き出す**：メニュー「エクスポート」→ **VRM**（バージョンは VRM 0.x か 1.0 のどちらかに統一。three-vrm は両対応だが混在させない）。エクスポート時の**ポリゴン/ボーン/テクスチャ**は既定でよい（重ければ削減）。
4. **ライセンス設定を確認**：エクスポート時のダイアログで**アバターの利用条件**（改変・再配布・商用）を設定/確認。**社内SaaS＝商用利用**なので、使う素材（プリセット衣装・テクスチャ）が**商用可**であることを必ず確認する。自作でも一部プリセットに条件が付く場合がある。
5. **ファイル名**：`male.vrm` / `female.vrm`（この名前だと結線が楽）。

### 4-2. 代替：既製VRMを入手
- **VRoid Hub / BOOTH / Sketchfab** 等で配布・販売の VRM を入手。**必ず商用利用の可否・クレジット要否を確認**（社内利用でも公開SaaSは商用扱いが無難）。
- 男女で別モデルを使う場合、**リグ（ボーン構成）が VRM humanoid 標準**であれば装備は共通化しやすい（バラバラだと装備を性別ごとに作り直しになる）。

### 4-3. 代替：3Dアーティストに発注
- ブランドに合わせたオリジナル。**発注仕様＝VRM humanoid・男女同一リグ・スロット（head/face/body/hand）に付く装備パーツ**を明記する（§2 の契約をそのまま渡す）。

### 4-4. ファイルの置き場所・サイズ
- 置き場所＝`impl/frontend/public/assets/avatar/`（例：`male.vrm`・`female.vrm`）。← ここに置いて（コミット）もらえれば私が読み込みます。
- **VRM は数MB〜十数MB**になりがち。リポジトリが太る場合は **Git LFS** の導入を検討（要相談）。装備パーツは1点ずつ小さめの glTF/glb でも可。

### 4-5. 装備パーツ（後回し可・大きめの作業）
- 各ショップアイテム（帽子/メガネ/武器/背景 等）を、**対応スロットのボーンに付く小物**としてモデリング（頭=頭ボーン、顔=顔、手持ち=手）。
- アイテム数ぶん必要＝**工数大**。**当面はベースだけ3D化し、装備は現状の2D重ねのまま**にするのが現実的（MVP）。

## 5. 私の作業＝コード結線（アセットが来たら）
1. `@pixiv/three-vrm` を追加（`impl/frontend`）。
2. `AvatarViewer3D.tsx` の `PlaceholderAvatar` を **VRM ローダに差し替え**（`base` で `male.vrm`/`female.vrm` を切替・回転・ライティング）。プリミティブ見立ては撤去。
3. WebGL 非対応/`prefers-reduced-motion`/アニメ設定（§4.9）尊重は維持。tsc/build と GF-AC で受入。
4. （装備3D化の段階）backend で `items.part_ref` を seed、item DTO に `part_ref` 追加→OpenAPI 再生成→スロットへアタッチ。それまでは装備は2D重ね継続。

## 6. 進め方（推奨ステップ）
1. **まず「ベースだけ3D化」を目標**にする（装備は2Dのまま）。
2. あなた＝§4 で `male.vrm`/`female.vrm` を用意し `public/assets/avatar/` へ。**ライセンス（商用可）を確認**。
3. 私＝§5-1〜3 を結線（回転・男女切替まで）。
4. 反応を見てから、装備の3Dアタッチ（§4-5/§5-4）へ段階的に。

## 7. 受入（完成の確認観点）
- WebGL 対応環境で `/avatar` に **実 VRM が表示・ドラッグ回転**できる。**男女ベース切替**でモデルが変わる（`users.avatar_base` 永続）。
- WebGL 非対応/reduce-motion で**フォールバック**（2D＋回転停止）に自動デグレード。
- ライセンス上の**商用利用条件を満たす**アセットである（記録を残す）。
- （装備3D化時）所有装備をスロットに付け替えると**3Dパーツが反映**される。
