# ideaquest

## 画面で見る機能ガイド ― できること

社内のアイデアを「**クエスト**」という単位で集め、**ISO 56001（イノベーション・マネジメントシステム）**が定める
イノベーション・プロセス（機会 → コンセプト → 検証 → 開発 → 導入）を、ゲーム感のある画面で**一気通貫**に回すアプリです。
本ガイドは、実際に使う**操作の流れに沿って**主な機能を紹介し、それぞれが **ISO 56001 のどの箇条に対応するか**を併記します。

> **ISO 56001 との関係**：本アプリは組織のイノベーション・マネジメントシステム（IMS）を支える運用ツールです。
> 中核は **箇条 8.3「イノベーションのプロセス」**（機会の特定 → コンセプトの創造 → コンセプトの検証 → ソリューションの開発 → ソリューションの導入）を、
> 端から端まで画面で運用できる点にあります。判定凡例＝◎強く支援／○部分支援。

---

## ― 01　クエストを立てて、取り組むテーマ（機会）を決める

アイデアを集めたいテーマを「クエスト」として起票します。目的・締切・参加メンバー（パーティー）・参加部署を決め、
「どのアイデアに何ができるか」の6つの権限を割り当てて、取り組みの器をつくります。

- ✓ テーマ・目的・締切・カテゴリーを設定してクエストを作成
- ✓ 参加メンバー（パーティー）と6つの権限（提案／投票／評価 等）を割り当て
- ✓ 「発見カタログ」で他部署に公開されたクエストを探して参加をリクエスト

**ISO 56001 対応**：**8.3.2 機会の特定**（◎）／**8.2 イノベーションの取組み**（○＝範囲・目的・役割の器）

---

## ― 02　外部の情報を集めて、判断材料（知識）として蓄える

Web 記事や市場の動きなどの外部情報を貼り付けて登録し、種別（機会／脅威）や優先度などの属性を付けて共有します。
登録した情報は、内容の近いアイデアやコンセプトへ**自動で関連付け**され、意思決定の裏付け・反証になります。

- ✓ タイトル＋本文＋出典URLで、会社の全員が手軽に登録
- ✓ 情報判定担当（キュレーター）が「機会／脅威」などの属性を付与・トリアージ
- ✓ 類似度による自動関連付け（双方向）＋主要語のワードクラウドで俯瞰
- ✓ 「この情報からクエストを作成」で、気づきをそのまま取り組みへ

**ISO 56001 対応**：**7.1.6 知識**（◎＝取得・分類・共有・活用）／**6.1 リスク及び機会**（○＝機会/脅威の運用）

---

## ― 03　アイデアを出し合い、投票・議論する

クエストのメンバーがアイデアを登録し、賛成／反対の投票と、アイデアごとのチャットで意見を交わします。
チャットや通知は**リアルタイム**で届き、活発な議論を後押しします。

- ✓ アイデアの登録・編集（提案価値・任意項目・添付・版管理つき）
- ✓ 賛成／反対の投票でメンバーの温度感を可視化
- ✓ アイデア単位のチャット（メンション・引用・リアクション・リアルタイム配信）

**ISO 56001 対応**：**8.3.3 コンセプトの創造**（◎＝アイデア生成）／**7.4 コミュニケーション**（◎）

---

## ― 04　アイデアを多面的に評価し、有望なものを見極める

評価者が、複数の観点を点数（5点満点）と観点別コメントで採点します。
「思いつき」で終わらせず、組織として選ぶための共通のものさしを提供します。

- ✓ 5つの観点で採点＋観点別コメントを記録
- ✓ 評価結果を集約し、有望なアイデアを見極め
- ✓ 評価という行動にも経験値・コインが付与され、参加を後押し

**ISO 56001 対応**：**8.3.3 コンセプトの創造**（◎＝評価・選択）／**9.1 評価**（○＝取組み単位の評価）

---

## ― 05　有望なアイデアをコンセプトへ昇華し、検証する

選ばれたアイデアを「コンセプト」に昇華し、成立に必要な**前提（仮説）**を「検証プール」で管理します。
反証（それを揺さぶる情報）も紐づけながら実現可能性を評価し、進める／方向転換／中止を判断します。

- ✓ 由来アイデアからコンセプトを起票（内容・議論・評価は昇華用に別立て）
- ✓ 検証プール（前提）で不確実性を管理し、支持／反証を紐づけて揺さぶる
- ✓ 実現可能性（viability）を中核5＋補助3の観点で評価
- ✓ go／pivot／kill の判定で、次のプロセスへ進めるかを決定

**ISO 56001 対応**：**8.3.4 コンセプトの検証**（◎＝不確実性・仮定のテスト）／**8.3.3**（◎＝コンセプト化）／**6.1 リスク及び機会**（○）

---

## ― 06　コンセプトから開発プロジェクトを起票し、タスクで進める

検証を通ったコンセプトを、開発プロジェクトとして起票します。タスクを任意の深さのツリーで管理し、
導入計画・KPI（価値実現の指標）まで記録して、ソリューションの開発から導入までをつなぎます。

- ✓ コンセプトから「開発を始める」、またはコンセプト無しの単純タスク管理でも起票
- ✓ タスクを親子ツリーで管理・担当割当・進捗集計
- ✓ 導入計画・KPI（価値実現の実測メタ）を記録
- ✓ タスク単位のチャットで、開発の議論も一元化

**ISO 56001 対応**：**8.3.5 ソリューションの開発**（◎）／**8.3.6 ソリューションの導入**（○＝導入・価値実現メタ）

---

## ― 07　go / pivot / kill と採否を記録し、意思決定を残す

各プロセスの節目で「進める・方向転換・中止」を判断し、成果物の採否（採用／保留／棄却）を記録します。
クエストの結果や振り返りとあわせて、意思決定の履歴が組織の学びとして残ります。

- ✓ 意思決定ポイント（go／pivot／kill）で継続・反復・中止を明確化
- ✓ 成果物の採否（disposition）を結果として集約
- ✓ クエスト結果・振り返り（retrospective）で成功／失敗から学ぶ

**ISO 56001 対応**：**8.3.1 プロセス（意思決定ポイント）**（◎）／**10.1 継続的改善**（○）

---

## ― 08　ゲーム感で、参加を続けたくなる仕組み

行動（アイデア投稿・投票・評価・ログイン等）に経験値やコインを付与し、レベルアップ・3Dアバターの着せ替え・
魔法スキル・実績バッジ・ランキングで、社内のアイデア創出を**楽しく継続**させます。

- ✓ 経験値（XP）・レベル・コインの獲得
- ✓ ショップでの装備購入と3Dアバターへの反映・着せ替え
- ✓ 魔法スキル・実績バッジ・クエスト内ランキング

**ISO 56001 対応**：**5.4 イノベーション文化**（◎＝創造性・開放性・フィードバック・学習）／**7.1.2 人材（インセンティブ）**（○）

---

## ― 09　すべての判断を記録・追跡できる（版管理・権限・監査）

クエスト・アイデア・コンセプトは版管理され、状態遷移や判定は意思決定ログに残ります。
権限に応じたアクセス制御と論理削除（証跡保持）で、後から「誰が・いつ・何を決めたか」を追跡できます。

- ✓ 版スナップショット（変更履歴）と意思決定ログ
- ✓ 6つの権限・二層メンバーシップ・情報判定権限によるアクセス制御
- ✓ 論理削除（トゥームストーン）で証跡を保持

**ISO 56001 対応**：**7.5 文書化情報**（◎＝作成・更新・管理・版・アクセス・保持）／**5.5 役割・責任・権限**（○）

---

## ― 10　会社・組織を安全に運用する（マルチテナント・職務分離）

1つのシステムに複数の会社が同居しつつ、**会社ごとに DB を物理分離**して機密を守ります。
管理は3階層のロール（職務分離）で分担し、参照はクエストグループ＋パーティーで制限します。

- ✓ 会社ごとの DB 物理分離による機密保護（簡易マルチテナント）
- ✓ 3階層ロール（システム管理者／会社アカウント管理者／クエストグループ管理者）で職務分離
- ✓ クエストグループ＋パーティー参加による参照制御

**ISO 56001 対応**：**5.5 役割・責任・権限**（○）／**6.5 組織構造**（△）

# 将来的に検討している機能

現状は ISO 56001 の「オペレーション（8.3 の5プロセス）」と「知識・コミュニケーション・文化・文書化」を強く支援しています。
今後は、上流の**計画・評価・戦略**の領域を埋める以下の機能を検討しています。

- **LLM（生成AI）との連携** ― アイデア・コンセプトの要約／分類／発想支援、情報の機会・脅威の判定補助、経営資料との**整合率のセマンティック算出**、前提に対する反証・リスクの洗い出しなどを、生成AIで支援します。**オンプレの無料LLMを既定**に、必要に応じてクラウドの高性能LLMを選択できる構成を想定します。
  - ➟ 横断的な支援（ISO **8.3.2 機会の特定** ／ **8.3.3・8.3.4 コンセプトの創造・検証** ／ **7.1.6 知識**）
- **経営資料との整合（整合率・機会/脅威率）** ― 会社の意図・方針・戦略・重点領域を構造化して登録し、アイデアやコンセプトとの**整合率**をコインで、情報の**機会/脅威率**を可視化。上流のブレを早期に発見します。
  - ➟ ISO **4.3 イノベーションの意図** ／ **5.2 方針** ／ **5.3 戦略**（文書化）の欠落を解消
- **イノベーションのポートフォリオ** ― クエスト／コンセプト／プロジェクトを横断し、リスク対リターン・新規性・成熟度・時間軸・機会分野などの基準で**優先順位付け**するビュー。
  - ➟ ISO **6.4 イノベーションのポートフォリオ**
- **イノベーション・パフォーマンス指標ダッシュボード** ― 洞察数・アイデア数・実験速度・導入件数・価値実現までの時間などを、input／throughput／output／result の体系で**定点観測**。
  - ➟ ISO **9.1 モニタリング・測定・分析・評価**
- **マネジメントレビュー支援** ― 既存データから、経営層のレビューに必要なインプットを自動で集約。
  - ➟ ISO **9.3 マネジメントレビュー**
- **（軽量）知的財産の管理／イノベーション目標の管理** ― IP の棚卸や、測定可能な目標のモニタリング。
  - ➟ ISO **7.1.7 知的財産** ／ **6.2 イノベーションの目標**
