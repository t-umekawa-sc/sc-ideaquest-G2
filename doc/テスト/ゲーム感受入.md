# ゲーム感 ブラウザ受入チェックリスト

> 目的＝「ゲーム感向上」フェーズの**視覚/操作感**をユーザーがブラウザで確認するための一覧。各項目に**一意ID（`GF-AC-NNN`）**を付ける。
> 使い方＝下表を上から操作して確認し、気になる点は **ID を添えて**指摘する（例：「GF-AC-002 のバー速度が速すぎる」）。自動テスト（純ロジックの vitest）は別途 `doc/テスト/I_ダッシュボード.md` の I-TC-150/151 で担保済み＝ここは**見た目の受入**に限定。
> 状態列＝`未確認`／`OK`／`要修正`（指摘は本人が記入 or 口頭）。

## 事前準備（並行ワークフロー）
- フロントをホストで起動＝`cd impl/frontend && npm run dev`（backend 一式は compose 稼働中・`/api` は自動で `localhost:8000` へプロキシ）。
- ブラウザ `http://localhost:3000` → ログイン `ACME-01` / `user@acme.example` / `Passw0rd!` → **ダッシュボード**。
- OS 設定「視差効果を減らす / reduce motion」を ON/OFF で切り替えて両方確認できると尚良い。

## 指摘の入れ方
- ID を添えて具体的に（速すぎる/遅すぎる・色・サイズ・位置・タイミング・出過ぎ/出なさすぎ 等）。
- 「対象を増やしたい」（例：ヘッダーのコイン表示・Lv・獲得XP総量にもカウントアップ）も歓迎＝次増分で拾う。
