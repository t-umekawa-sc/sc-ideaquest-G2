## 1. 概要・目的

- 自分が投入した **AIジョブ**（LLM 要約・生成等）の「**処理待ち / 実行中 / 完了・失敗**」を1画面で把握し、**完了選択で生成結果を反映した対象画面へ遷移**する。
- 初版（Phase1）は**バックグラウンド専用**＝各機能から enqueue → ここで進捗を追い、完了は通知（SC-02）でも受け取る。
- 導線＝**共通ヘッダーのベル近傍のバッジ**（実行中/待ち件数＝`GET /ai-jobs/summary`）／SC-02 通知の `ai_task_done`/`ai_task_failed` からも到達。

## 2. アクセス条件・権限

| 項目 | 内容 |
| --- | --- |
| アクセス可能者 | 認証済みユーザー全員（**自分のジョブのみ**・`requested_by_id` スコープ・他人のジョブは 404） |
| 生成 | 各機能の enqueue（or `POST /ai-jobs`）でサーバーが `ai_jobs` を作成（§5.57） |
| 運用閲覧 | `system_admin` は運用向けに閲覧可（S.0） |

## 3. レイアウト構成（決定・業務層）

- 上部＝戻るピル（SC-02 と同型）＋**状態サマリ**（待ち/実行中/直近完了・失敗の件数＝`GET /ai-jobs/summary`・バッジ）。
- 本体＝共有 DataTable（サーバー委譲）1枚。状態フィルタ（待ち/実行中/完了/失敗）＋種別フィルタ。
- **ライブ**＝WebSocket `ai_jobs:{user_id}`（§L）で待ち件数/実行中/進捗をリアルタイム反映（ポーリング不要）。

## 4. 表示・入力項目

### 4.1 一覧テーブル（DataTable・サーバー委譲）

| 列 | 内容 |
| --- | --- |
| タスク種別 | 日本語ラベル＋アイコン（`info_summarize`＝要約 等） |
| 状態 | バッジ（待ち/実行中/完了/失敗/キャンセル） |
| 進捗 | **実行中は進捗バー**（`ai_jobs.progress` の `phase`/`ratio`＝§5.6）。任意で部分プレビュー |
| 依頼時刻 | `created_at`（相対表示） |
| 完了時刻 | `finished_at`（完了/失敗時） |
| 対象 | `ref_*`（アイデア/クエスト/経営資料/情報）＝クリックで該当画面へ |

- 既定ソート＝新着降順（`created_at desc`）。フィルタ＝`status`/`task_type`（サーバークエリ §1.8.1）。

### 4.2 行アクション

- **実行中＝キャンセル**（`POST /ai-jobs/{id}/cancel`・協調キャンセル §S.4）。実行中はライブで進捗バーが伸びる。
- **完了＝対象へ遷移**（`ref_*`・通知クリックと同じ動線＝「内容を参照する」）。
- 失敗＝`error.detail` をツールチップ/詳細で表示（再投入は各機能側の操作）。

## 5. アクション・遷移

- 行の `ref_*` → アイデア詳細(SC-22)/クエスト(SC-12)/経営資料(SC-81)/情報(SC-52) 等へ（生成結果を反映した状態）。
- ベルバッジ／SC-02 通知（`ai_task_done`）→ 本画面 or 直接対象へ。
- キャンセル → 行が `canceled` に更新（ライブ）。

## 6. データ・API（正＝`S_AIジョブ・LLM連携.md`）

- 一覧＝`GET /ai-jobs`（DataTable §1.8.1）／サマリ＝`GET /ai-jobs/summary`／詳細＝`GET /ai-jobs/{id}`／キャンセル＝`POST /ai-jobs/{id}/cancel`。
- ライブ＝WebSocket `ai_jobs:{user_id}`（§L・§1.12）。完了通知＝`notifications`（`ai_task_done`/`ai_task_failed`・§H）。

## 7. アクセシビリティ / 表示配慮

- 進捗バーは `aria-valuenow`／状態はテキスト併記（色のみに依存しない）。ライブ更新は `aria-live=polite`。
- アニメ（進捗バー・完了演出）は OS reduce OR `accounts.reduce_motion` を尊重（デザイン標準 §4.9）。

## 8. 状態・バリエーション

- ジョブ0件＝空状態（「現在 AI 処理はありません」）。
- 実行中0・待ち複数＝順次処理（N=1 既定）を明示（「N 件待機中・順に処理します」）。
- WS 切断時＝`ai_jobs.progress`/`GET` で復元（**画面が状態の正**）。
