## 1. 概要・目的

- 会社アカウント管理者が、プラットフォームが提供する **LLM モデル（論理キー）のカタログ**から**自社で使うモデルを ON/OFF** し、**有料モデルには月次予算上限**を設定する。
- **利用量/コストの可視化**（会社×モデル×月）＝課金方式 A（内部メータリングのみ・実請求なし）＝「使った量と費用が見える・上限で止められる」を確立。
- 導線＝**会社アカウント管理者の管理エリア（SC-93 と同じメニュー）**の「AI・LLM設定」から（company_account_admin の自社向け設定＝会社固定・クロステナント不可）。

## 2. アクセス条件・権限

| 項目 | 内容 |
| --- | --- |
| アクセス可能者 | **`company_account_admin` / `system_admin`**（一般ユーザーは不可・403） |
| 表示 | カタログ（registry 全キー・§4.1）＋自社設定（`company_ai_model_settings`・§5.58）＋当月利用量/コスト |
| 変更 | ON/OFF トグル・月次予算＝管理者のみ。**`paid` を ON＝課金合意**（確認ダイアログ） |

## 3. レイアウト構成（決定・業務層）

- 上部＝当月の会社サマリ（総コスト・予算消化率・実行件数）。
- 本体＝モデル一覧テーブル（カタログ×自社設定）。行＝モデルごとに ON/OFF トグル・課金区分バッジ・月次予算・当月利用。
- 下部/別タブ＝利用量明細（会社×モデル×月＝`GET /admin/ai-usage`）。

## 4. 表示・入力項目

### 4.1 モデル一覧テーブル

| 列 | 内容 |
| --- | --- |
| モデル | 表示名＋**特徴・用途**（論理キー・例「Qwen3 Swallow（日本語生成）」＋「日本語生成が得意／要約・アイデア整形向き」）。backend admin 応答は `key` のみ返すため、表示名・特徴・用途は**フロント側の metadata マップ**（キー→`{表示名, 特徴, 用途}`）で補う（Phase1 は qwen3-light/qwen3-swallow の2キー）。管理者が「どのモデルを何に使うか」を判断できるようにする。 |
| 課金区分 | `free`（自社ホスト）/`paid`（外部・従量）バッジ |
| 外部送信 | `external`＝外部クラウド送信の有無（データ主権の明示） |
| 有効 | **ON/OFF トグル**（`free` 既定 ON／`paid` 既定 OFF） |
| 月次予算 | `paid` のみ入力可（`monthly_budget_micros`・空＝無制限） |
| 当月利用 | トークン・概算コスト・予算消化率 |

### 4.2 ON/OFF・予算の操作

- `paid` を ON にする＝**確認ダイアログ**（「有料モデルを有効化します＝利用量に応じて課金が発生します。外部送信も解禁されます」）＝**課金合意＋データ主権解禁が同一操作に集約**（§S.7）。`enabled_by`/`enabled_at` を記録。
- 予算上限＝到達で `paid` の enqueue を保留/拒否（無料ローカルは対象外）。

## 5. アクション・遷移

- トグル ON/OFF → `PATCH /admin/ai-models/{key}`（`paid` ON は確認モーダル経由）。
- 予算変更 → 同 `PATCH`。
- 利用明細 → `GET /admin/ai-usage`（`?period_ym=`/`?model_key=`）。
- 会社アカウント管理者の管理エリア（SC-93 近傍）へ戻る。

## 6. データ・API（正＝`S_AIジョブ・LLM連携.md` S.5）

- 一覧＝`GET /admin/ai-models`（registry＋`enabled`/`billing`/`monthly_budget_micros`/当月利用）。
- 変更＝`PATCH /admin/ai-models/{key}`（`enabled?`/`monthly_budget_micros?`）。
- 利用量＝`GET /admin/ai-usage`（`ai_usage_events` の read 集計・§5.59）。

## 7. アクセシビリティ / 表示配慮

- トグルは `aria-pressed`／課金区分・外部送信は色のみに依存せずテキスト併記。
- `paid` ON の確認モーダルはデザイン標準の確認モーダル（フォーカストラップ・Esc 閉じ）。

## 8. 状態・バリエーション

- カタログが自社ホスト無料キーのみ＝ON/OFF は実質固定表示（候補1）＋「有料モデルは未提供」。
- 予算未設定（無制限）＝消化率は非表示／実費のみ。
- 当月利用0＝「利用実績なし」。
