# SC-80/81/82 経営資料（一覧・登録/編集・詳細）— FR-44・ドメイン R

> 正＝要件 [FR-44](../../要件定義/README.md)／API [R_経営資料・整合](../../API設計/R_経営資料・整合.md)／データモデル [§5.54/§5.55/§5.56](../../データモデル.md)／設計元 [経営資料整合・自動関連付け 設計](../../設計ドラフト/経営資料整合・自動関連付け_設計.md)。横断標準＝[デザイン標準](../デザイン標準.md)（DataTable §4.5・入力検証 §4.7・複製 §4.5・ガイダンス §4.13）。

## 0. 位置づけ・権限
- 会社の基準文書（中長期計画/方針/戦略）を **ISO56001 の項目立て**で N 件登録・管理する管理者画面。
- **登録/編集/アーカイブ/削除＝会社アカウント管理者（`company_account_admin`）／`system_admin`**（機微・R.0）。
- 導線＝サイドバー「管理 > 📕 経営資料」（**companyAdmin または systemAdmin に表示**＝backend 認可と一致）。

## 1. SC-80 一覧
- 共有 **DataTable**（サーバー委譲・§4.5）＝検索（q＝title/本文）・種別/状態の列絞り込み・ソート・ページ。
- **カード/リスト 表示形式トグル**（他一覧と統一）。カード＝タイトル＋状態バッジ＋種別/対象期間/更新日。
- 操作列（先頭・左端固定・⋮）＝**編集 → 複製 → アーカイブ（active時）／復元（archived時）**（標準メニュー順・§4.5）。**物理削除は設けない**＝基本は論理削除（アーカイブ）に統一（機微・監査保持・プロジェクト慣例）。カード形式は ⋮ を**右上**に置く。
  - **複製**＝登録ダイアログを「追加モード」で選択行の値をプリフィルして開く（`/strategy-documents/new?from=<id>`・タイトルに「（複製）」・別レコード新規作成・§複製標準）。
- 「＋ 経営資料を登録」＝URL 付きモーダル（`/strategy-documents/new`）。

## 2. SC-81 登録/編集（URL 付きモーダル・§4.1）
- 冒頭に **ⓘ「この画面について」**（ScreenPurpose・§4.13）＝クエストで選ぶと配下アイデアの関連度を出す旨。
- 入力項目（ISO56001 対応）＝**タイトル**（必須）／**種別**（中期経営計画/方針/戦略/その他）／**対象期間**（開始・終了）／**重点領域**（自由入力ありの複数選択＝`.tagselect` チップ＋候補・style-guide「複数選択（自由入力あり）」）／**意図・ビジョン**（§4/§5.1）／**方針・コミットメント**（§5.2）／**戦略・方向性**（§6.1）／**目標**（§6.2）／**補足・全文**。
- **ISO が要求する項目（意図/方針/戦略/目標/重点領域）はラベル横に icon-only ⓘ**（ScreenPurpose＝ホバー要約・クリック全文）で「何を書くか」を解説（§4.13）。
- 検証＝§4.7 の4部品（Field error／FormSummary／useFormErrorNotice／FormFooterError）。タイトル必須・対象期間の開始≤終了（422）。
- 保存＝作成後は詳細へ遷移せず**閉じて一覧へ戻る**（登録ダイアログ閉じ標準・§4.1）。`body_text` 連結＋`entity_tokens`（owner='strategy_doc'）同期。
- **この資料の主要語（ワードクラウド）**＝「🔑 キーワードを抽出」＋主要語プレビュー（**情報登録ダイアログと同一UI**・`.wc-preview`/`.wc-mini`）。保存時に janome で `entity_tokens` へ。
- **紐づくクエスト（編集時のみ・R.1b）**＝情報詳細の「関連リンク」と同型＝一覧（チップ）＋「＋ クエストを紐づける」→検索ピッカー（**全社の有効クエスト**）→追加／各チップ ✕ で解除。**変更は当該クエストの版履歴（quest_revision）に記録**（クエスト側フォームからの選択と同じ中間表 `quest_strategy_documents`）。

## 3. SC-82 詳細（Step4 で拡充）
- 全項目＋**機会率/脅威率/影響率**（`impact_class` 集計・R.4）＋ワードクラウド＋関連情報/アイデア＋Markdown エクスポート（R.5）。**Step4/5 で実装**（本スライスは一覧＋登録/編集）。

## 4. クエストへの適用（Step2B）
- クエスト作成/編集に「適用する経営資料（複数選択）」を追加（`quest_strategy_documents`・§5.56・参加グループ選択と同 UI）。選択元＝`GET /strategy-documents?for=selection`（クエスト作成権限者に開放）。選択変更は quest_revision を1版追加（版履歴）。
