## 1. 概要・目的

- **認証済みユーザー本人**が、**自己プロフィール**（表示名・言語・プロフィール画像）と**セキュリティ**（パスワード・メールアドレス）を取得・編集する画面。あわせて**残高（レベル / XP / コイン / スキルポイント）を読み取り表示**する。
- 導線＝**共通ヘッダーのユーザーメニュー →「プロフィール」**（`K_プロフィール・背景画像.md` K.0）。`/me`＝**セッションの `account_id`／自分のみ**（他人のプロフィール参照/編集は不可）。
- **プレーンをまたぐ**（K.0）: identity（表示名 / メール / 言語 / パスワード）＝**管理DB `accounts` が源泉**（編集は `accounts` 更新＋同一Tx で `account_sync_outbox`・会社DB `users` はミラー）。プロフィール画像・背景画像＝**会社DB `users` 所有**（MinIO）。残高＝**会社DB `users`（読み取り専用・canonical は G の `activities`）**。
- **本画面が持たないもの（別画面）**: **3D アバターの着せ替え（装備）＝ドメイン G・[SC-31 アバター着せ替え](./SC-31_アバター着せ替え.md)**（VRM スロット・`PUT /me/equipment`）。**背景画像の変更/リセット＝ヘッダーのユーザーメニュー**（FR-30・`K_プロフィール・背景画像.md` K.4）。※3D アバター（VRM）と**プロフィール画像**（`avatar_image_path`＝一覧/ランキング/コメントのアイコン・K.4）は**別物**。本画面には 3D アバターを**読み取り表示**し、着せ替えは SC-31 へ導線する。

## 2. アクセス条件・権限

| 項目 | 内容 |
| --- | --- |
| アクセス可能者 | **認証済みユーザー全員・自分のみ**（`/me`＝`session.account_id`/`company_id`）。未認証＝**401** |
| 対象 | **本人のアカウントのみ**（他アカウントの参照/編集経路を持たない＝IDOR 対策・K.5②） |
| できること | **表示名・言語（ja/en）の編集**（`PATCH /me`）／**プロフィール画像の設定・削除**（`PUT`・`DELETE /me/avatar-image`）／**パスワード変更**（`POST /me/password`）／**メールアドレス変更の要求**（`POST /me/email`＝ダブルオプトイン） |
| できないこと（本画面では不可） | **ログインID・システムロール・状態・残高（レベル/XP/コイン/SP）の変更**（Mass Assignment allowlist＝想定外プロパティは `422 validation_error` で拒否・K.0/コーディング規約 §2.2）。**3D アバターの着せ替え**（＝SC-31）・**背景画像**（＝ユーザーメニュー） |
| 再認証 | **パスワード変更・メールアドレス変更は現在のパスワードで再認証**（不一致＝`403 reauth_failed`・セッションは有効なので 401 と区別・K.0/ADR-0008 同コード） |

## 3. レイアウト構成（決定・テナント層）

- **共通ヘッダー**（残高チップ Lv/コイン/SP ＋ベル＋アバターメニュー。ユーザーメニューに「背景画像を変更／リセット」）。
- **backlink**「← ダッシュボードへ戻る」＋**ページタイトル「プロフィール」**＋概要リード（表示名・プロフィール画像・言語／セキュリティ／※3D アバターは「きせかえ」・背景画像はユーザーメニュー）。
- **アカウント情報カード（読み取り専用）**: **3D アバタービューア**（読取・「▶ きせかえ（装備を変更）」「🛒 ショップ」導線）＋**氏名**＋**システムロール**バッジ＋**残高**（レベル＋次レベルまでの XP バー＋コイン＋SP）＋**identity**（会社 / ログインID / メールアドレス / システムロール）。
- **プロフィール編集カード**: プロフィール画像（アイコン）／表示名／言語 ＋「保存する」。
- **セキュリティカード**: パスワード変更 ／ メールアドレス変更（2 小節）。
- **末尾 role-note**（PW 変更で全端末ログアウト・メール変更はリンクで確定・変更不可項目の明示）。
- **レスポンシブ（狭幅 ≤640px）**＝3D アバターは**中央寄せ**、identity は 1 列縦積み、編集の設定行は縦積み（アイコン＋ボタンを説明の下にゆったり配置）。

## 4. 表示・入力項目

### 4.1 アカウント情報＋残高（読み取り専用・`GET /me`）
- **3D アバター**＝キャラクター表示（本番は three-vrm/R3F・モックは見立て）。**読み取り表示**で、着せ替え（装備）は [SC-31](./SC-31_アバター着せ替え.md)（ドメイン G）へ導線。
- **氏名（display_name）**・**システムロール**（一般／会社アカウント管理者／システム管理者＝読み取りバッジ）。
- **残高**＝**レベル**・**XP バー**（`xp`/`xp_to_next`・「NEXT n XP」）・**コイン**（`coin_balance`）・**スキルポイント**（`skill_point_balance`）。**表示のみ**（canonical は G の `activities`）。`xp_to_next`/`level_span` は G の純粋 level 関数で算出（`K_プロフィール・背景画像.md` K.1）。
- **identity**＝会社（company_code）／**ログインID（変更不可・固定）**／メールアドレス（変更は 4.3）／システムロール。
- **impl レイアウト（2026-08-19）**: 3D アバター表示グループ（アバター＋氏名＋ロール＋残高）と**獲得履歴（4.1b）**を**最上部のゲーム風パネル（`pixel-panel`）にまとめて配置**。identity（会社/ログインID/メール/ロール）は「ユーザ情報」見出しのカードへ分離。XP バーはホバーで獲得XPのツールチップ（SC-01 ダッシュボードと共通様式）。

### 4.1b 獲得履歴（`GET /me/activities`・G.6／FR-36・実装済み）
- **自分の付与/消費の元帳を新しい順で表示**（全種別＝私的行動含む・本人のみ）。各行＝事由の日本語ラベル（ログインボーナス/アイデア投稿/選定/実績報酬/レベルアップ/ショップ購入/魔法解放…）＋増減（獲得＝金 `＋N XP/◆/✦`・消費＝赤 `−N`）＋相対時刻。「もっと見る」でカーソル追加読込（§1.8）。
- **源泉＝会社DB `activities`**（canonical・データモデル §5.27）。読取専用 EP `GET /me/activities`（`kind?`/`period?`/`cursor`・API設計 [G.5.1](../../API設計/G_ゲーミフィケーション.md)）。他者に見せるフィード（SC-01/SC-12）は成果系のみ公開だが、**本画面は自分の履歴なので全種別**を表示（データモデル §8-㉑）。

### 4.2 プロフィール編集（`PATCH /me`・`PUT`/`DELETE /me/avatar-image`）
- **プロフィール画像（アイコン）**＝一覧・ランキング・コメント等に表示される**アイコン画像**（`avatar_image_path`・会社DB `users` 所有・MinIO）。**3D アバターとは別**（着せ替えは SC-31）。未設定時は「頭文字＋カラー」でフォールバック表示。画像アップロードは MinIO 基盤前提で今後対応（モックはローカルプレビュー）。設定＝`PUT /me/avatar-image`（multipart）、削除＝`DELETE /me/avatar-image`。
- **表示名（必須）**・**言語**（`ja`/`en`・enum）。**`PATCH /me` はこの 2 つのみ受理**（allowlist＝`{display_name?, locale?}`・K.2）。`display_name`/`locale` は `accounts` 源泉＝管理DB 更新＋同一Tx で `account_sync_outbox` INSERT（会社DB `users` ミラーはワーカが結果整合・応答は更新値を即返す＝楽観的表示）。
- **メール・パスワードは本 EP では変更しない**（K.2）＝セキュリティ（4.3）へ。

### 4.3 セキュリティ（`K_プロフィール・背景画像.md` K.3）
- **パスワード変更**＝現在のパスワード（必須・再認証）／新しいパスワード／新しいパスワード（確認）。**完了で当該アカウントの全アクティブセッション破棄＋信頼端末失効**（`A_認証・セッション.md` §A.9-③）＝**要再ログイン**。`security_password_changed` 通知＋メールを発火（K→H・§A.9-⑧(b)）。PW ポリシー（最低文字数・漏えい/よく使われる PW 拒否＝§A.9-④）はサーバー検証。
- **メールアドレス変更**＝新しいメールアドレス／現在のパスワード（必須・再認証）。**ダブルオプトイン**（[ADR-0008](../../ADR/ADR-0008_メール変更のダブルオプトイン.md)）＝新メールへ**確認リンク**（TTL 24h）を送付し、**リンクを開くまで未反映**（`accounts.pending_email` で pending）。旧メールへ**変更通知**（乗っ取り検知）。確定は `POST /me/email/confirm`（未認証＝トークンが認可）。

## 5. アクション・遷移

| トリガー | 条件 | 遷移/結果 |
| --- | --- | --- |
| 保存する（プロフィール編集） | 表示名必須 | `PATCH /me {display_name?, locale?}` → 更新後の `/me` を反映＋共通ヘッダーの表示名を更新（楽観的表示・ミラーは結果整合） |
| 画像を選ぶ / 削除（既定に戻す） | — | `PUT`/`DELETE /me/avatar-image`（MinIO・署名URL 応答）。※MVP はローカルプレビュー（MinIO 待ち） |
| パスワードを変更（要再ログイン） | 現PW一致・新PW=確認・ポリシー可 | `POST /me/password` → **全端末ログアウト**（§A.9-③）→ `/login` へ。通知＋メール発火 |
| 確認メールを送信（メール変更） | 現PW一致・会社内一意 | `POST /me/email` → **202**（新メールへ確認リンク・旧メールへ通知）。この時点では未反映（pending） |
| （メール確認リンク） | トークン有効 | `POST /me/email/confirm {token}` → **確定**（`email=pending_email`・ミラー enqueue）。セッション破棄はしない（ADR-0008） |
| ▶ きせかえ（装備を変更） | — | [SC-31 アバター着せ替え](./SC-31_アバター着せ替え.md) へ遷移（3D アバターの装備＝ドメイン G） |
| 🛒 ショップ | — | [SC-30 ショップ](./SC-30_ショップ.md) へ遷移 |
| 背景画像を変更／リセット | — | **ヘッダーのユーザーメニュー**（本画面外・FR-30・`PUT`/`DELETE /me/background-image`） |

## 6. データ・API（正＝`K_プロフィール・背景画像.md`）

- **GET `/api/v1/me`**（K.1）: 自分のプロフィール＋残高（正準）＝`{account:{login_id,email,locale}, profile:{display_name, avatar_image_url?, background_image_url?}, balance:{level,xp,xp_to_next,level_span,coin_balance,skill_point_balance}, system_role}`。会社DB `users` から読み、画像は**短TTL 署名URL**で返す（パス直返し禁止・§1.10）。
- **PATCH `/api/v1/me`**（K.2）: `{display_name?, locale?}`（**この 2 つのみ**受理）→ 200＋更新後の `/me`。accounts 更新＋`account_sync_outbox`（単一コントロールプレーン Tx）。
- **POST `/api/v1/me/password`**（K.3）: `{current_password, new_password}` → 204（**全セッション無効＝要再ログイン**）。
- **POST `/api/v1/me/email`**（K.3・ADR-0008）: `{new_email, current_password}` → 202（確定待ち・pending）。**POST `/api/v1/me/email/confirm`** `{token}`（未認証） → 200（`{status:"confirmed"}`）。
- **PUT `/api/v1/me/avatar-image`**（multipart `file`）／**DELETE `/api/v1/me/avatar-image`**（K.4）: プロフィール画像の設定/削除（会社DB `users` 直接・outbox 経由せず・署名URL 応答）。
- 背景画像（`PUT`/`DELETE /me/background-image`）は**ユーザーメニュー**の担当（本画面外・K.4）。
- **Mass Assignment（K.0/§2.2）**＝各編集 EP は受入フィールドを allowlist。**残高・`system_role`・`status`・`password_set`・`login_id` は編集不可**（想定外プロパティ＝`422 validation_error`）。認可失敗＝403／未認証＝401／再認証失敗＝`403 reauth_failed`。

## 7. アクセシビリティ / 表示配慮

- 読み取り専用項目（identity・残高・3D アバター）と編集項目を視覚的に分離。**変更不可**（ログインID/システムロール/残高）は role-note とカード注記で明示。
- パスワード変更＝**「完了で全端末ログアウト（要再ログイン）」を事前に明示**。メール変更＝**「リンクを開くまで確定しない・旧アドレスに通知」を明示**（誤操作・不安の低減）。
- スイッチ/選択・入力にラベルを関連付け（フォーム項目は `label`＋`for`）。
- **狭幅レスポンシブ**＝3D アバターは中央寄せ、identity は 1 列、設定行は縦積みでボタンが窮屈にならないようにする。

## 8. 状態・バリエーション

| 状態 | 表示 |
| --- | --- |
| プロフィール画像 未設定 | 「頭文字＋カラー」でフォールバック表示 |
| メールアドレス変更 pending | 「確認メールを送信しました（リンクで確定）」。`email` は未変更のまま |
| パスワード変更 完了 | 全端末ログアウト → `/login`（セキュリティ通知＋メール） |
| 言語 切替 | `ja`/`en`（UI 文言に反映＝i18n） |
| 未認証 | 401 → ログインへ |
