# ISO 56001:2024 準拠状況 再チェック（2026-09-28）

> ISO 56001:2024 全文（`doc/ISO56001/C2_ISO_56001_2024_01.pdf`＝英和対訳版・全67p）の**要求事項（箇条4〜10）を精読**し、本システム（ideaquest）の実装との対応を条項別に再評価したもの。前回までの ISO 対応記述（[FR-39 ISO56001 との関係](../設計ドラフト/FR-39_ISO56001との関係と設計意図.md)・[コンセプト機能 ISO56001 再設計](../設計ドラフト/コンセプト機能_ISO56001_再設計.md)）を、正規の全文で裏取りし更新する位置づけ。

## 0. 前提（重要な枠組み）

- **ISO 56001 は「組織」が構築する“イノベーション・マネジメントシステム(IMS)”の要求事項**。認証の主語は組織であって、ソフトウェアではない。
- 本システムは組織の IMS を**支える運用ツール（デジタル基盤）**。したがって本書の「準拠」は **「各条項の達成を本アプリがどれだけ支援・運用可能にしているか」** を評価する（トップマネジメントのコミットメント等、本質的に組織活動である条項はアプリ単体では満たせない＝`N/A(組織)` と表記）。
- 判定凡例：**◎=強く支援 / ○=部分支援 / △=弱い・周辺 / ×=未対応(要検討) / N/A(組織)=アプリ対象外の組織活動**。

## 1. 総括

- **最強一致＝箇条8.3「イノベーションのプロセス」**（機会の特定→コンセプトの創造→コンセプトの検証→ソリューションの開発→ソリューションの導入）。本アプリの中核ループ（クエスト/情報→アイデア→コンセプト/検証→プロジェクト/導入）が**この5プロセスを端から端まで運用可能**にしている＝IMS の“operation”層の実体。
- **強い一致**＝7.1.6 知識（情報インプット＝知識レイヤ）・7.4 コミュニケーション（チャット/通知/リアルタイム）・5.4 イノベーション文化（ゲーミフィケーション/協働/フィードバック）・7.5 文書化情報（版管理/意思決定ログ/権限/トゥームストーン）。
- **主要ギャップ（製品として埋める価値が高い順）**：
  1. **6.4 イノベーションのポートフォリオ**（評価・優先順位付け基準を持つ横断ポートフォリオ）＝**未実装**。
  2. **9.1 イノベーションのパフォーマンス指標**（input/throughput/output/result の体系的 KPI）＝**部分**（クエスト結果KPI・評価・XP等はあるが IMS 指標として体系化されていない）。
  3. **4.3 イノベーションの意図 / 5.2 方針 / 5.3 戦略**（文書化情報）＝**未実装**（→ [経営資料整合・自動関連付け 設計](../設計ドラフト/経営資料整合・自動関連付け_設計.md) で対応予定）。
  4. **6.2 イノベーションの目標**・**7.1.7 知的財産**・**7.1.4 財務/資金調達**・**9.3 マネジメントレビュー**・**9.2 内部監査**＝未対応/組織側。

## 3. 準拠を高めるための提案（ロードマップ接続）

1. **経営資料エンティティ（設計中）** が **4.3 意図 / 5.2 方針 / 5.3 戦略** の文書化を埋める＝ISO 準拠上の“上流の欠落”を直接解消（[経営資料整合・自動関連付け 設計](../設計ドラフト/経営資料整合・自動関連付け_設計.md)）。整合率は 9.1 の result 指標の一部にもなり得る。
2. **6.4 イノベーションのポートフォリオ**＝新規候補。クエスト/コンセプト/プロジェクトを横断し、**評価/優先順位基準（リスク対リターン・新規性・TRL・時間軸・機会分野）**でランク付けするビュー。ISO の明確な要求かつ現状ギャップ＝価値高。
3. **9.1 イノベーション・パフォーマンス指標ダッシュボード**＝input(洞察/取組み数)・throughput(アイデア/コンセプト数・実験速度)・output(導入件数/速度)・result(ROII/満足度/インパクト)。既存データ(件数/評価/XP/導入)を IMS 指標として再集計。整合率/機会脅威率もここに載る。
4. 中期＝**9.3 マネジメントレビュー支援**（インプット自動集約＝9.3.2 の a〜i を既存データから編纂）／**7.1.7 知的財産**の軽量管理／**6.2 イノベーション目標**。

## 4. 結論

- 本システムは **ISO 56001 の“オペレーション”（箇条8.3 の5プロセス）と“知識・コミュニケーション・文化・文書化”を強く支援**しており、IMS の実行基盤として高い適合度を持つ。
- 一方、**“計画”のポートフォリオ(6.4)と“評価”のイノベーション指標(9.1)・“上流”の意図/方針/戦略の文書化(4.3/5.2/5.3)** が主要ギャップ。うち上流文書化は経営資料機能で対応予定、ポートフォリオと指標は新規実装候補として価値が高い。
- なお本書は「アプリの支援度」の評価であり、**組織としての ISO 56001 認証取得は別途、組織の方針/監査/レビュー等の運用が必要**（アプリはその大部分の証跡・運用を保持できる）。
